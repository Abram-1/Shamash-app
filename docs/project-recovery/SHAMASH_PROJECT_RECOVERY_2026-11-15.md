## 3. Решения владельца
- SHAMASH — единый оркестратор строительного управления, SAFETY только одна из частей, сейчас главный практический приоритет.
- MASTER ARCHITECTURE сохраняется, изменения только через согласованный контроль; владелец принимает решения.
- Координация ChatGPT → Codex (код/тесты) → Claude (независимый аудит по необходимости) → ChatGPT → владелец. Уменьшать ручную пересылку, но не выдавать желаемую интеграцию за работающую.
- Параллельно максимум 2–3 направления, сейчас SAFETY, ORCHESTRATOR и CORE.
- SAFETY: 15 языков в плане; первая группа he-IL, ru-RU, en-US, fr-FR, de-DE; два голоса на язык.
- Утвержденные примеры качества/тембра: Sadaltager (муж., иврит), Zephyr (жен., иврит), Algenib (муж., французский), Callirrhoe (жен., французский). Эти образцы Google Chirp 3 HD НЕ означают согласие на платный сервис.
- ОБЯЗАТЕЛЬНО: бесплатная озвучка без платежей за голосовой сервис. Проверить браузерные голоса и локальные открытые TTS; лицензии, качество и доступность иврита пока не доказаны.
- Не изменять действующее приложение, не публиковать, не использовать реальные данные работников, не запускать платные API без отдельного разрешения.
